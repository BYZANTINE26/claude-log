# Branch: feature/core-logging-mvp

## Purpose
Implement the Core Logging MVP for claude-log: an append-only,
per-session, per-project JSONL log that batches each turn (via
UserPromptSubmit + PostToolUse + Stop hooks and a per-turn buffer) into a
single 1-2 line summary, generated by a rule-based stub summarizer sitting
behind the real pluggable HTTP contract.

## Goal
Land a working, tested implementation matching
`.claude/plans/PLAN.md`: the `claude_log/` package, `bin/` hook wrappers,
`tests/`, hook registration in `.claude/settings.json`, and a verified
manual smoke test in a real Claude Code session.

This branch does NOT cover: a real local summarization model, the
benchmarking suite vs. claude-mem, or any BACKLOG.md items — those are
separate, later work.
